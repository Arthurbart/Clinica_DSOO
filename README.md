# Sistema de Gerenciamento de Clínicas

Sistema desenvolvido em Python para o gerenciamento de informações e registros de uma clínica, aplicando os conceitos de **Programação Orientada a Objetos (POO)** e o padrão arquitetural **MVC (Model-View-Controller)**.

## Funcionalidades

- **Cadastro de pessoas:** gerenciamento de pacientes e profissionais.
- **Cadastro de clínicas:** registro de clínicas e suas informações.
- **Tipos de atendimento:** gerenciamento dos tipos de atendimento disponíveis.
- **Atendimentos:** registro de consultas e procedimentos realizados.
- **Procedimentos:** cadastro e gerenciamento de procedimentos vinculados aos atendimentos.
- **Pagamentos:** registro e gerenciamento de pagamentos, com diferentes formas de pagamento, como dinheiro, cartão e PIX.
- **Relatórios:** organização e consulta das informações registradas no sistema.

## Tecnologias e conceitos

- **Python 3**
- Programação Orientada a Objetos (POO)
- Arquitetura MVC (Model-View-Controller)
- Herança, encapsulamento e classes abstratas
- Tratamento de exceções
- Organização modular do código

## Organização do projeto

O projeto está organizado em três camadas principais:

- **Models:** contém as classes e entidades do sistema, como pacientes, profissionais, clínicas, atendimentos, procedimentos e pagamentos.
- **Views:** contém as interfaces responsáveis pela interação com o usuário.
- **Controllers:** gerencia a lógica da aplicação, conectando as interfaces às classes do sistema.

## Objetivo

Este projeto tem como objetivo aplicar os conceitos de orientação a objetos no desenvolvimento de um sistema organizado em módulos, facilitando a manutenção do código e a integração entre as diferentes funcionalidades de gerenciamento de clínicas.
